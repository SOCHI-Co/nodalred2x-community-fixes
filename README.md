# Nodal Red 2x community fixes

Unofficial fixes for Nodal Red 2x, the Nord Lead 2X emulation by The Usual Suspects (https://theusualsuspects.io, https://github.com/dsp56300/gearmulator). Based on 2.2.25. Windows, VST3. You still need your own ROM.

- Stuck notes fixed on layered performances
- Official Clavia names and categories for all 396 factory programs and 100 performances
- No more window walking in FL Studio, sized with a SIZE - / + control instead
- Real names instead of numbers in the display, button click areas that don't overlap

Download the zip from Releases, unzip it somewhere like Downloads, close your DAW and run Install.bat. The full source diff is in the zip.
